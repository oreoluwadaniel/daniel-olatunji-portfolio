# Daniel Olatunji — Portfolio

**Data Analyst | Business Intelligence Analyst — Lagos, Nigeria**

Live: **https://daniel-olatunji-portfolio.vercel.app**

I turn business numbers into a clear view of what is happening, where attention is needed, and what should happen next.

This repository contains the presentation layer for the portfolio. It highlights four case studies across product experimentation, forecasting, data quality, and CRM data governance, with the supporting repositories linked where available.

## Case studies

| Project | Field | Repository |
| --- | --- | --- |
| A/B Testing & Product Experimentation | Product analytics | [repo](https://github.com/oreoluwadaniel/ab-testing-case-studies) |
| WeatherIntel: Weather Data & Forecast Testing | Forecasting, data engineering | [repo](https://github.com/oreoluwadaniel/weatherintel-global-weather-analytics) |
| Data Quality & Business Reporting | Data quality, reporting | [repo](https://github.com/oreoluwadaniel/data-analytics-etl-portfolio) |
| Kavora CRM Migration & Data Governance | CRM, data governance | [repo](https://github.com/oreoluwadaniel/kavora-crm-migration-data-governance) |

## Stack

Next.js · React · TypeScript · CSS custom properties

## Running locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Deployment

Deployed on Vercel from `main`. GitHub Actions builds the application on pushes and pull requests.
